# Agentic Emergency Tele-Triage & Autonomous Medical Dispatch System

Project documents for the controller-managed, three-agent prototype supporting English and Egyptian Arabic.

The controller coordinates the conversation, triage and guidance, and coordination agents. The latest presentation and flowchart follow this architecture, with simulated emergency resources and authorized test receivers.
